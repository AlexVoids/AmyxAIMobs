# Проверки AmyxAIMobs 1.0.0

## Автоматические проверки

- PHP: синтаксис производственных файлов и тестов, минимальная проверенная версия PHP 8.1.34; также PHP 8.4.16.
- `php tests/rules.php`: 20 проверок A* и правил конфигурации. Обход стены, непроходимая пропасть, замкнутое пространство, отрицательные координаты, лимит раскрытых узлов и истёкший временной бюджет; ненарушение заданных настроек, вложенные исключения мира, ограничения высоты/времени/света/биома, нулевой вес и предел размера группы.
- `tools/test-server.py`: 14 сценариев на реальном серверном ядре с производственным PHAR. Используются настоящий World, блоки, коллизии, EntityFactory и NBT. Синтетический Player/NetworkSession заменяет соединение с клиентом в сценариях с игроком; сам графический клиент не запускается.
- В сценарии регистрации создаются и восстанавливаются из NBT **72 вида**, включая отдельно зарегистрированного дракона. Это проверка загрузки/сохранения сущностей, а не доказательство полноты их поведения.

Проверенные официальные ядра:

| PocketMine-MP | PHP | Сценарии |
| --- | --- | --- |
| 5.0.0 | 8.1.34 | 14 |
| 5.28.0, Minecraft 1.21.80 | 8.4.16 | 14 |
| 5.44.3, Minecraft 26.30 | 8.4.16 | 14; дополнительно запуск с данными старого плагина |

Серверные сценарии проверяют:

1. Сохранение комментариев нового конфига либо перенос старых настроек и JSON без удаления оригинала.
2. Регистрацию, создание и NBT-восстановление видов.
3. Обход высокой стены и проверку безопасности каждой точки пути.
4. Отказ от лавы, ограждения, опасного обрыва и незагруженного чанка.
5. Последнее видимое положение цели и отсутствие сброса таймера памяти при повторном выборе невидимой цели.
6. Сохранение остановки скелета для стрельбы при обновлении общего контроллера.
7. Вычисление настоящего движения по маршруту.
8. Проверку расстояния, выключенного мира/вида, нулевого лимита, уровня света, мирной сложности и творческого режима игрока.
9. Недопущение переполнения общего лимита рыбьим косяком.
10. Реальный естественный спавн группы на подходящем участке с ограничением количества.
11. Сохранение брони, повреждённого здоровья и размера детёныша.
12. Следование детёныша за взрослым, кормление в творческом режиме без расхода еды.
13. Дыхание при погружении головы вместо намокания ног, иммунитет ифрита к огню.
14. Заполнение недостающих ключей конфига без замены нулей, лимитов и пользовательских правил.

Команды:

```bash
php tests/rules.php
python3 tools/test-server.py --php /path/to/php --pmmp /path/to/PocketMine-MP.phar
python3 tools/test-server.py --php /path/to/php --pmmp /path/to/PocketMine-MP.phar --legacy-fixture
```

Для PM 5.0.0 нужен совместимый старый PHP: ядро содержит зависимости, несовместимые с PHP 8.4. Серверные запуски выполняются последовательно, поскольку помощник пересобирает общий PHAR. Миры и журналы создаются в исключённой из Git папке `work`.

## Практические ограничения и проверка на сервере владельца

Точная Windows-сборка NG-PocketMine-MP 5.39.1 не предоставлена. Её запуск, все протоколы клиентов 1.18–26.30, графические анимации, торговля, транспорт, поведение всех редких видов и производительность при большом числе игроков не проверялись. Совместимость API исследовалась также по открытым исходникам NG-PocketMine-MP; это не заменяет запуск точной сборки.

После установки проверьте `/aimobs status`, преследование зомби вокруг стены, остановку/отход скелета, детёныша рядом с родителем и размножение. Затем установите небольшой общий лимит, дождитесь естественного появления и убедитесь, что косяки его соблюдают. Для проверки сохранения экипируйте/повредите моба, перезапустите сервер и сравните состояние. Изменения конфига применяются через `/aimobs reload`.

## Артефакты

Сборка создаёт только производственный PHAR. Установочный ZIP содержит этот PHAR и README, архив исходников — проект без `work`, `.git`, тестовых миров, секретов, временных файлов и вложенных сборок. SHA256SUMS.txt проверяет все три файла; release workflow повторно проверяет суммы перед публикацией.
