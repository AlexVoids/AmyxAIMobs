# AmyxAIMobs

Мобы и естественный спавн для PocketMine-MP 5.x, на основе переданного AZVanillaMobs 2.0.18 (BeeAZ). Исходные пространства имён и NBT-идентификаторы сохранены для загрузки уже существующих сущностей. MIT-лицензия и авторство исходника сохранены в LICENSE.

[Скачать последний релиз](https://github.com/AlexVoids/AmyxAIMobs/releases/latest) · [Настройки спавна](resources/config.yml) · [Изменения](docs/RELEASE_NOTES.md) · [Проверки](docs/TESTING.md)

В **1.0.1** исправлен урон от дневного горения зомби и скелетов: уже горящим мобам больше не сбрасывается отсчёт огня на каждом шаге AI. Урон начисляет само ядро с сохранением событий и защиты от огня.

## Установка и переход с AZVanillaMobs

1. Остановите сервер и сохраните резервную копию миров и папки данных `AZVanillaMobs` (`plugins` или `plugin_data`).
2. Уберите старый PHAR AZVanillaMobs из `plugins`. Эти плагины нельзя запускать вместе: у них общие классы, яйца и идентификаторы сущностей.
3. Поместите **AmyxAIMobs.phar** в `plugins` и запустите сервер. FormAPI и другие сторонние плагины не требуются.
4. При первом запуске, если ещё нет конфига AmyxAIMobs, плагин копирует YAML/JSON из папки `AZVanillaMobs` (проверяются соседняя папка данных, `plugins` и `plugin_data`), сохраняя исходную папку. Настройки администратора, включая нулевые лимиты, не перезаписываются. Сохранённые сущности читаются по прежним NBT ID.
5. Меняйте `config.yml` в папке данных AmyxAIMobs (точный путь показывает `/aimobs status`); применяйте `/aimobs reload`. Параметры уже созданных мобов не заменяются новым видом или количеством автоматически.

Перенос не удаляет мобов, миры и старые файлы. Обновления устанавливаются заменой одного PHAR при остановленном сервере. Горячая выгрузка/загрузка класса плагина через сторонние менеджеры не поддерживается.

## Поведение

- Кешируемый A* для наземных мобов: обход стен, подъём на один полный блок, спуск не более трёх блоков, проверка ширины и высоты тела, препятствий, ограждений и опасных блоков. Поиск работает только в загруженных чанках, с общими ограничениями времени и количества поисков за тик.
- Преследование по последней видимой позиции, ограниченная память цели. Повторный выбор невидимой цели больше не продлевает память бесконечно.
- Скелеты и разбойники могут остановиться для выстрела или отойти от близкой цели: общий контроллер больше не заменяет их цель движения принудительным сближением.
- Детёныши следуют за ближайшим взрослым того же вида. Размер детёныша восстанавливается при загрузке. Кормление в творческом режиме не расходует еду. Размножение требует видимости партнёра.
- Броня сохраняется в собственном NBT-теге, здоровье не восстанавливается полностью при загрузке некоторых видов. Наземные животные по умолчанию сохраняются вдали от игроков; именованные, приручённые, привязанные и структурные мобы защищены от естественного удаления.
- Дыхание проверяется по погружению глаз: мелкая вода не заставляет наземных мобов задыхаться. Наземные мобы гребут вверх, воздушно-дышащие водные мобы всплывают при нехватке воздуха. Для соответствующих адских видов добавлен иммунитет к огню.
- Сохранены исходные механики боя, паники, приручения, размножения, транспорта, поводков, торговли жителей, дропа, структур и особенности отдельных видов. Странствующий торговец остаётся отключённым в естественном спавне, его старое яйцо проходит прежнюю безопасную миграцию.

## Спавн

Файл с комментариями: [`resources/config.yml`](resources/config.yml). При работе сервера: **`plugin_data/AmyxAIMobs/config.yml`** или **`plugins/AmyxAIMobs/config.yml`**, в зависимости от настроек ядра. `/aimobs status` и журнал запуска показывают точный путь. Названия видов слитные, в нижнем регистре: `zombievillager`, `tropicalfish`, `witherskeleton`.

| Параметры | Действие |
| --- | --- |
| `natural-spawning` | Главный выключатель естественного спавна |
| `spawn-cycle-seconds`, `spawn-chance-percent` | Интервал проверки (минимум 4 секунды), шанс выбранного чанка (0–100) |
| `spawn-chunks-per-player`, `spawn-attempts-per-chunk` | Объём работы на цикл (2–10 чанков и 1–4 попытки) |
| `spawn-successes-per-world` | До 1–8 успешных групп в мире за цикл; каждый участник отдельно проверяет лимиты |
| `spawn-min-player-distance`, `spawn-max-player-distance`, `spawn-radius-chunks` | Дистанции в блоках и радиус отбора загруженных чанков (2–8 чанков) |
| `global-mob-cap` | Общий предел загруженных мобов плагина на сервере, в том числе ручных и структурных |
| `per-world-mob-cap`, `local-mob-cap`, `local-mob-cap-radius` | Пределы в мире и в окрестности точки появления |
| `per-world-hostile/passive/aquatic-cap`, `local-hostile/passive/aquatic-cap` | Пределы категорий; «passive» включает невраждебных водных мобов, у которых есть дополнительный водный предел |
| `entity-type-limits` | Общесерверный предел загруженных мобов каждого вида; 0 запрещает новый естественный спавн |
| `mobs.<вид>.enabled`, `weight-multiplier` | Разрешение и множитель исходного биомного веса (0 отключает). Не отменяет правила биома |
| `mobs.<вид>.min-y/max-y`, `time`, `max-block-light`, `biomes` | Дополнительные ограничения высоты, времени, света блоков и точных названий биома |
| `mobs.<вид>.group-min/max` | Размер группы коров/овец/свиней/кур и рыб/кальмаров, включая первого участника (1–16) |
| `world-overrides` | Исключения по имени папки мира, включая полное отключение |
| `hostile-max-block-light` | Свет блоков для естественного появления враждебных мобов обычного мира; по умолчанию 0 для профиля 1.18+ |
| `passive-require-grass` | Для коров/овец/свиней/кур/лошадей/ослов требовать травяной блок под точкой появления |
| `despawn-passive`, `natural-despawn-distance` | Удаление далёких естественных мобов; наземные животные по умолчанию сохраняются |
| `structure-spawning` | Дополнительное автоматическое заселение структур, по умолчанию выключено; ручные команды структур сохранены |
| `ai` | Поиск пути, интервал перепланирования и ограничения нагрузки |

```yaml
world-overrides:
  lobby:
    enabled: false
  survival:
    per-world-mob-cap: 70
    spawn-chance-percent: 60
    mobs:
      creeper:
        enabled: false
      zombie:
        weight-multiplier: 1.5
        min-y: -64
        max-y: 80
        time: night
        max-block-light: 0
```

Изменения в `world-overrides` поддержаны для `enabled`, `natural-spawning`, пределов мира/местности, шанса, дистанций и радиуса спавна, ограничения света, `passive-require-grass`, `entity-type-limits` и `mobs`. Глобальный лимит и интервал цикла остаются общесерверными.

Спавн не загружает новые чанки, не запускается только ради игроков в творческом режиме/наблюдении, не создаёт мобов ближе минимальной или дальше максимальной дистанции. Группы проверяют актуальные пределы перед каждым участником. Враждебные мобы не появляются в мирной сложности. Эти ограничения относятся к естественному появлению; яйца, размножение и ручные команды имеют собственные исходные правила.

## Команды

- `/aimobs status` — путь к конфигу, число и виды загруженных мобов по мирам.
- `/aimobs reload` — перечитать конфиг; не удаляет уже существующих мобов.
- Сохранены исходные `/summon`, `/azkill`, `/mobsworld`, `/mobsnether` и команда заполнения сундуков структур. У всех административные права. Если имя занято другим плагином, используйте префикс `/amyxaimobs:имя`.
- Новое право `amyxaimobs.admin` по умолчанию у оператора; исходные `azvanillamobs.command.*` сохранены для совместимости с правами сервера.

## Границы реализации

Это улучшение существующего серверного AI, а не полная реализация внутреннего движка Bedrock. Полёт и плавание используют исходную навигацию; наземный поиск консервативен на полублоках и лестницах и не открывает/ломает двери. При исчерпанном бюджете моб может ждать следующего расчёта. Механики рейдов, полноценного ИИ боссов и редких видов не воссозданы целиком; часть классов исходника имеет лишь общее поведение. Мультипротокольное ядро отвечает за поддержку сетевых типов сущностей клиентами разных версий.

Проверено на официальных сборках PocketMine-MP, см. TESTING.md. Точная Windows-сборка NG-PocketMine-MP 5.39.1 пользователя и графический Bedrock-клиент в среде отсутствуют; тесты не означают проверки всех видов и механик в клиенте.

## Сборка

```bash
php -d phar.readonly=0 tools/build.php
php tests/rules.php
python3 tools/test-server.py --php /путь/к/php --pmmp /путь/к/PocketMine-MP.phar
python3 tools/package-release.py
```

В `build` находятся PHAR, архив для установки, архив полных исходников и SHA-256. PHAR включает только `src`, `resources`, `plugin.yml` и исходную лицензию; тестовые миры, кеши и вложения в публикацию не входят.
